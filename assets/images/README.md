# Logo

Drop your logo file here as **`logo.png`** (this exact filename — it's
already wired up in `includes/layout.php`, `login.php`, and `pages/403.php`).

Recommended: a square image, at least 256×256px, PNG with a transparent
background (it sits inside a gradient rounded-square in the sidebar and on
the login page, so transparency lets that background show through).

Until this file exists, the app falls back to the default truck icon
everywhere it's used — nothing breaks, it just won't be your logo yet.
